# payload-plugin-branching

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)
[![Payload](https://img.shields.io/badge/payload-%5E3.0.0-black)](https://payloadcms.com)

A [Payload CMS](https://payloadcms.com) plugin that brings Git-like branching to your content. Payload's built-in drafts give you one working copy per document, but this plugin lets you create multiple named branches, edit content in isolation on each, and switch between them, without touching your live/default content until you're ready.

## Status

Early development. Not yet published to npm.

## Planned features

- Create named branches off any collection's content
- Edit documents within a branch without affecting the default branch
- Built on top of Payload's native versions/drafts system

Installation and usage docs will be added once the plugin has a working first release.

## Requirements

- Payload `^3.0.0`
